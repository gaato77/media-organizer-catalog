# Catalog 1950–2015 Design

## Goal

Generate a resumable historical catalog for every year from 1950 through 2015, then consolidate those annual shards into one validated SQLite release package without modifying the existing 2016–2025 artifact.

## Architecture

A manual GitHub Actions workflow runs one matrix job per year. The matrix contains 66 years, limits concurrency to two jobs, and saves each annual output in an independent cache and artifact. A dependent consolidation job downloads all completed annual artifacts, validates that every year is present, deduplicates records by Wikidata QID, builds the compact SQLite release, validates it, and uploads one review artifact.

## Scope

- Include years 1950 through 2015, inclusive.
- Do not query 2016–2025 again.
- Do not include 1888–1949 or 2026 in this workflow.
- Preserve annual caches so failed runs can resume.
- Keep the workflow manual only.
- Limit Wikidata concurrency to two annual jobs.
- Produce `complete-1950-2015-catalog-probe`.
- Do not publish a GitHub Release.
- Do not modify the existing 2016–2025 package.

## Data Flow

1. Verify tests, formatting, typing, and SQLite smoke checks.
2. Generate or reuse one annual shard for each year from 1950 to 2015.
3. Validate each annual shard contains `summary.json`, `movie.json`, and `series.json`, with `month_count == 12` and the expected year.
4. Upload each completed annual shard as `year-YYYY`.
5. Download all 66 annual artifacts into a deterministic year directory tree.
6. Consolidate with the existing network-free annual-shard consolidator.
7. Build and validate the SQLite release package.
8. Upload the review artifact `complete-1950-2015-catalog-probe`.

## Failure and Retry Behavior

Each annual cache uses a year-specific restore prefix. A retry restores completed or partially completed work for that year. The matrix uses `fail-fast: false`, so one failing year does not cancel unrelated years. Consolidation only runs after all annual jobs complete successfully.

## Validation

Tooling tests must assert the manual trigger, exact year range, two-job concurrency, annual cache pattern, artifact upload/download, network-free consolidation, and final artifact name. The full Python test suite, Ruff, mypy, and smoke lookup must remain green.
