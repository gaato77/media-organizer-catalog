# Catalog 1950–2015 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manual, resumable GitHub Actions workflow that generates annual catalog shards for 1950–2015 and packages them into one validated compact SQLite artifact.

**Architecture:** Reuse the existing annual probe and network-free shard consolidator. Add one dedicated workflow with a 66-year matrix, `max-parallel: 2`, independent year caches/artifacts, and a final consolidation/package job.

**Tech Stack:** Python 3.12, pytest, Ruff, mypy, SQLite, GitHub Actions cache/artifact actions.

## Global Constraints

- Work only on `feature/catalog-1950-2015` until verification succeeds.
- Keep the workflow manual only.
- Include every year from 1950 through 2015 exactly once.
- Do not query years 2016–2025.
- Do not include 1888–1949 or 2026.
- Limit Wikidata concurrency to two annual jobs.
- Preserve independent annual caches for resumability.
- Produce `complete-1950-2015-catalog-probe`.
- Do not publish a GitHub Release.
- Do not alter the existing 2016–2025 workflow or artifact.

### Task 2: Add the resumable 1950–2015 workflow

**Files:**
- Create: `.github/workflows/probe-wikidata-1950-2015.yml`

**Interfaces:**
- Consumes: `builder/scripts/probe_wikidata_year.py`, `builder/scripts/consolidate_year_shards.py`, `build_probe_release`.
- Produces: annual artifacts `year-1950` through `year-2015` and final artifact `complete-1950-2015-catalog-probe`.

- [ ] **Step 1: Create the manual workflow header and verification job**

Use:

```yaml
name: Complete 1950-2015 catalog probe

on:
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: complete-1950-2015-catalog-probe-${{ github.ref }}
  cancel-in-progress: false
```

Add the existing full verification commands: pytest, Ruff check, Ruff format check, mypy, and smoke lookup.

- [ ] **Step 2: Add the 66-year matrix job**

Set:

```yaml
strategy:
  fail-fast: false
  max-parallel: 2
  matrix:
    year:
      - 1950
      # every year exactly once
      - 2015
```

Restore/save `year-probe-output` with keys beginning `year-probe-${{ matrix.year }}-`, run `probe_wikidata_year.py --limit 50000`, validate the three annual files and `month_count == 12`, and upload `year-${{ matrix.year }}`.

- [ ] **Step 3: Add the consolidation and release job**

Download `year-*`, assemble `multi-year-probe-output/years/YYYY` for `seq 1950 2015`, run:

```bash
python builder/scripts/consolidate_year_shards.py \
  --output-dir multi-year-probe-output \
  --start-year 1950 \
  --end-year 2015
```

Then call `build_probe_release` and upload `complete-1950-2015-catalog-probe` with the consolidated summary, release directory, SQLite, lookup cases, skip audit, and consolidation log.

- [ ] **Step 4: Run focused tooling tests**

Run:

```bash

```

Expected: all tooling tests pass.
